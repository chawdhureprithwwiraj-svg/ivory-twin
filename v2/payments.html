The list every room keeps

Every room this house has ever opened was stored with an empty guest list, and the house’s own view reads that list — so no member has ever been let in, whatever the floor said. Nothing a page can write survives. This one line makes the house fill the list itself, from each room’s floor, before the room is stored — for every room from now on. Run it once, then open a room and watch: open to will list the tiers instead of saying nobody.

create or replace function public.ivory_keep_the_list() returns trigger
language plpgsql security definer set search_path = public as $$
declare mx int;
begin
  if new.allowed_tiers is null or cardinality(new.allowed_tiers) = 0 then
    select coalesce(max(level), 4) into mx from public.subscription_tiers where is_active is not false;
    if coalesce(new.min_tier, 1) <= mx then
      new.allowed_tiers := array(select generate_series(greatest(coalesce(new.min_tier,1),1), mx));
    end if;
  end if;
  return new;
end $$;

drop trigger if exists ivory_keep_the_list on public.live_sessions;
create trigger ivory_keep_the_list
  before insert or update on public.live_sessions
  for each row execute function public.ivory_keep_the_list();

Paste it into the Supabase SQL editor and run it once. It is safe to run twice. After that a Reader walks into a Reader room, an Insider into an Insider room, and the live page stops asking you for anything.
